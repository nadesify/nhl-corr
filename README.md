# NHL stack correlations

Live page: https://nadesify.github.io/nhl-corr/

How much NHL players' DraftKings points rise and fall together, from real game logs, grouped by tonight's lines.
Open the page and tap "How to read this". Add `#EDM` (any team code) to the link to open on one team.

Updated automatically. A reading aid for building stacks, not a prediction of who scores tonight.
